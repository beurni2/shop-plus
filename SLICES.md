# SLICES — Shop+ Building Plan ledger

**LIVRES-1 (AUDIT-SHOP-2 F-39).** The Building Plan's slice ids were never tracked as such: only `SP0.1` and `SP6.1` appear in JOURNAL.md headers, and eight ids are never named there. This ledger maps every plan slice (`docs/Shop-Plus-Building-Plan.md` §Phase 0–3) to what the repository actually holds, with the evidence a reader can open. It is kept **by hand, in the same commit as the slice that moves a row** — JOURNAL.md stays the narrative; this is the index.

**Statuses:** DONE · PARTIAL (what is missing is named) · NOT STARTED · SUPERSEDED (needs the founder's word to close the plan line) · GATED. **Device matrix:** every plan DoD requires « offline verified · low-end Android / interrupted-network »; **no journal entry carries a device-matrix line** (F-39). The column below records what exists instead — the driven walks and the offline/low-end proofs — never a claim that the matrix was run. Evidence names journal entries by their title (`JOURNAL.md`), files, gates in `scripts/run-gates.sh`, and the AUDIT-SHOP-2 ledger (`_review/AUDIT-SHOP-2.md` §7) where a property was measured there.
